Noise is any information, whatever its origin or intent, that detracts from the current moment of the communication; future ideas are fine only when they add value.

## Context
Matt, 22 Oct 2026, ruling on the stage 1 post. The failure case is a 'magic string': the draft brought in the scorer's expected terms, never prompted for or run, as if they caused the 'ok' result. That left a gap instead of filling one. Test each sentence: does it fill a gap the reader has now, using only what the story has set up? Never present something unused as a cause, and never frame an unprompted gap as the agent failing.
