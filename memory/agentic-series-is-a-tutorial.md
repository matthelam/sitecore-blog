The Agentic Studio series is a hands-on tutorial, so every run action is shown with what and why, and context artifacts made off camera are opened on camera and mapped to the Studio structure they feed.

## Context
Matt: 'every action needs to be recorded and visible so they can see exactly what we are doing and why'; artifact creation need not be recorded, but the video switches to each document to show what is in it, how it relates to the brand kit structure, and how each section works as context to the prompt. The run sheet is structured around the lesson.
