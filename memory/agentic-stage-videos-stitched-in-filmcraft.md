Agentic Studio stage videos are stitched and built in FilmCraft, so a recording need not be one end-to-end take; plan it as segments recorded separately and stitched together afterwards.

## Context
Plan where each segment starts and ends so the pieces can be stitched together in FilmCraft afterwards.
