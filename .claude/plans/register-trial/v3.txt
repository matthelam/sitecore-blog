We're settling on how to hand context to an agent. Root instruction files, skills, layered system prompts, a few memory approaches. That's real progress, and it's good at one thing: documenting **Prescriptive Context**. The rules and standing guidance an agent is told to follow.
===
Prescription only goes so far. I keep stepping back into the loop. To ask the right question. To push the agent down a different path. To hand it a hard-won insight, or the right tool at the right moment. That's experience, and it's a different kind of context. Less structured than the rules. More the _ah-ha_ moment that saves the day. I call it **Reflective Context**, and right now it doesn't have a home. The memory containers are sophisticated, but I think there's a heap more clarity needed in how we hook them up.
===
I have to admit, I started out putting all my research and testing into one massive white paper. I kept finding holes in my logic and my testing, and kept finding real implementations I needed to look at. I've been stuck for two months trying to articulate what I've prototyped, and I'm missing the latest updates in the field. So this post gets the framework out. Updates will follow as more posts, plus a structured write-up per platform on how each lines up with the Legal Framework. To be clear, there are a LOT of tools now edging closer to this idea. Some may argue one has already surpassed it. That's fine. I'll keep documenting the real implementation across platforms, and hopefully it's a useful baseline.
===
We've landed on a well-described structure for _prescriptive_ rules. We also worked out early that an agent needs memory, or something closer to fine-tuning through context. RAG and vector stores, the LLM wiki, MCP data sources.
===
I'm not challenging that we have those. I'm challenging **how we reach for them, and when**. We load memory like everything else: up front, indiscriminately, as standing context. Wrong time, wrong shape. **Experience is precedent. It only matters once the rules in front of you have run out.**
