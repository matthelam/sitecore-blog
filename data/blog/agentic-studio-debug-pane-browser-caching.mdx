**In short:** add `debug=true` to the end of the Agentic Studio conversations URL and the debug console opens as a panel on the right. The setting was cached in the browser, so when the panel didn't appear, ctrl+f5 was the fix. Sitecore Support verified that as a real issue, and recent releases have resolved it.

Some might find this super useful when building Agents in Agentic Studio. There is a hidden debug console!

## How to open it

You open it by adding `debug=true` to the end of the conversations URL, as described in [Troubleshoot chats](https://doc.sitecore.com/sai/en/users/sitecoreai/working-with-agentic-studio/understanding-chat/troubleshoot-chats.html):

```js
https://app-sitecore.cloud/agentic/conversations?tenantName=<TENANT_NAME>&organization=<ORG_NAME>&debug=true
```

1. Open the conversations URL with `debug=true` on the end.
2. Look for the panel on the right.
3. If it isn't there, hit ctrl+f5. That was needed before the fix described below.

## If the panel didn't appear

A quirk I noticed to be aware of when using it though was that the setting is actually cached on the browser and so if the right panel doesn't appear hit the ctrl+f5 so that it picks up the setting in the querystring.

**Update:** Sitecore Support verified that this was a real issue. Recent releases have resolved it, and the agent now runs normally. Learning about the debug panel is still valuable, so the rest of this post stands.

> The visible pane is the only proof the flag took effect. Not the URL, not the fact that you pressed enter.

## Can you debug standard agents?

**One more trap while you're here.** [Troubleshoot agents](https://doc.sitecore.com/sai/en/users/sitecoreai/working-with-agentic-studio/understanding-agents/troubleshoot-agents.html) says, flatly, "You cannot debug standard agents." That's true of the workflow editor's Run facility. It is not true of this pane, which lists standard agent runs quite happily — mine is showing ten of them right now. Two debug surfaces, two documentation pages, and a restriction that only applies to one of them. I nearly gave up on the strength of that one sentence.

Check the pane is there. Then start debugging.
